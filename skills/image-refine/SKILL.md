# 图片调整迭代（image-refine）

输入：上一轮生成的图片（+ 用户的不满意点）。输出：调整后的图片。

> **本 skill 不是新的生成类型**（无独立 workflow/`comfyui_api.py` 子命令），它是**编排层**：
> 复用 `text-to-image`（seed 重 roll / 改词重跑）与 `image-to-image`（基于上一张迭代）。
> 完整"症状→杠杆"决策表见 `references/refine.md`（**单一事实来源**），本文件只留精炼版。

## 流程

1. **先问两句，先定"重新生成 vs 基于旧图迭代"**（`references/refine.md` §一）：
   - **第 1 句——这张该不该留作基准？** 用户**完全不喜欢/要推翻** → 回到文生图**重新生成**（不基于旧图）；
     用户**骨架满意、只调局部/方向** → 才基于上一张迭代。⚠️ **别把被否定的图当 `--image` 基准**（会继承讨厌的质感/构图）。
   - **第 2 句——同方向换实例，还是换方向？** 少动（这版不理想/只改一小点）→ 种子/低 denoise；
     大动（风格/场景/主体错/质量差）→ 改词/换模型/高 denoise。
2. **定基准图与本轮改动轴**：基准 = 上一轮**输出图**（`outputs/<类型>/<时间戳>_xxx.png`，脚本已自动下载的本地路径）；
   每轮**只动一个主导轴**，其余参数固化。记录迭代上下文（见 §迭代上下文）。
3. **按决策表选杠杆并调用**（下表为精炼版，完整与**参数档位速查**见 `references/refine.md`）：

| 不满意点 | 杠杆与命令 |
|---|---|
| **完全不喜欢，要推翻重来** | **重新生成**（文生图同词换 seed / 改词 / 换模型；**不基于旧图**） |
| 只是这版不理想 | 同词同参仅换 seed：`text-to-image --prompt "..." --seed <新>`，或 `--batch N` 连出多张 |
| 细节/局部要改 | 基于上一张迭代：`image-to-image --image <上轮输出> --denoise 0.3–0.45 --prompt "改成什么"` |
| 风格/材质/场景大改 | `--denoise 0.75–0.9`，或换 `--checkpoint` + 风格 LoRA（须 `validate`） |
| 主体/构图本身错 | 改词后重跑：改主体/构图词 + `text-to-image` 重跑，或 `image-to-image` 大改 |
| 质量不够（糊/噪/畸形） | `--steps 28–35`、微调 `--cfg`、加画质词、换高清底模 |
| 想多选 | `--batch N` 或固定参数连出不同 seed |
| 只想改特定区域 | ⚠️ 不支持（无 inpaint/ControlNet 模板）；向用户说明并询问是否新增工作流 |

4. **交付报告**：按 `references/reporting.md` 的**迭代版**汇报——标注**这是第 N 轮**、**相对上一轮改了什么轴 + 为什么**、列出**上一轮基线**作为对照；给出 `preview_url`（图片内联）与本地路径。

## 迭代上下文（每轮必带，**不限轮数**）

```
【迭代上下文】第 N 轮   # N 可为任意轮（2、3、10...），不限次数
- 类型/工作流/模型：image-to-image / default_sd15_img2img / oneObsession_v23
- 基准输入图：第 N-1 轮输出（outputs/<类型>/<时间戳>_xxx.png）
- 基线参数：上轮 prompt / negative / seed / denoise / steps / cfg / 尺寸
- 本轮改动：<改了什么轴 + 为什么>
- 固化项：做 A/B 时固定 seed，除变化轴外其余参数不变
```

- **可复现**：同 seed + 同词 + 同参 ≈ 同结果；若这版不如上版，用固化 seed/参数复现上版回滚。
- **可对比**：每轮只动一个轴，才能判断是否该改动带来的。
- **可继续**：下一轮基准 = 这一轮输出，形成链。

## 反馈收敛闭环

交付后给用户明确下一步选项，而非直接结束：

- 满意 → 保留；
- 再微调 → 第 N+1 轮（默认沿用"就近"杠杆，除非用户改了方向）；
- 大改方向 → 重新路由（换模型/换风格/换构图）；
- 回退 → 用固化 seed/参数复现上一版。

## 边界

- **局部重绘/inpaint/ControlNet/IP-Adapter**：无对应模板，标注为"不支持，需新增工作流"；
- **seed 复现性**：同服务端+同模型下同 seed+同词 ≈ 同结果；跨模型/LoRA 不保证，目标定位为"相对上一轮做 A/B"。
